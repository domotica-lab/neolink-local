# Neolink Local

Telecamere **Reolink**, anche **a batteria e P2P** (Argus, Go, Duo,
videocitofoni…), in Home Assistant come stream **RTSP locali**, senza cloud.
Le camere a batteria si svegliano solo mentre le guardi e tornano a dormire
appena chiudi.

Apri la scheda **Documentazione** per configurazione, valori consigliati e
risoluzione dei problemi.
